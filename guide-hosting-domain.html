1마침 ← 이전 페이지로 돌아가기
호스팅 · 도메인 준비 가이드

내 사이트를 올려둘 "집"과
"주소"를 먼저 준비해주세요.

1마침은 사이트를 만들어서 올려드리는 역할이고, 사이트가 실제로 켜져 있는 호스팅 서비스와 도메인(주소)은 고객님 명의로 직접 가입·구매해주세요. 그래야 사이트가 온전히 고객님의 것이 돼요. 아래 순서대로 따라 하시면 보통 20~30분이면 끝나요.

이 준비는 시안 승인 후, 개발이 진행되는 동안 해주시면 돼요. 준비가 늦어지면 배포도 그만큼 미뤄져요. 전체 소요 시간은 보통 20~30분이에요. (계정 가입 5분 · 초대 3분 · 도메인 구매 10~15분)
1

배포 서비스(Cloudflare)에 가입하기 · 약 5분

1마침은 모든 사이트를 Cloudflare(Pages)에 올려드립니다. 이메일만으로 가입할 수 있고, 개인 홈페이지 규모는 보통 무료 요금제 안에서 운영됩니다.

이렇게 해주세요
① 인터넷 주소창에 dash.cloudflare.com 을 입력해 들어가요. 검색해서 들어가실 때는 주소가 정확히 cloudflare.com 으로 끝나는지 확인해주세요.
② "회원가입(Sign up)"을 눌러 이메일과 비밀번호를 정하고 가입해요. 신청서에 적어주신 이메일로 가입해주세요.
③ 이메일로 온 인증 메일의 확인 링크를 눌러요. (메일이 안 오면 스팸함을 먼저 확인해주세요.)
④ 로그인이 되면 끝이에요. 요금제를 고르는 화면이 나오면 무료(Free)를 선택해도 개인 사이트는 충분해요. 결제수단 등록은 하지 않으셔도 돼요.

계정은 반드시 고객님 명의로 만들어주세요. 1마침은 아이디·비밀번호를 받지 않아요.

💡 화면 모양은 서비스 회사가 바꿀 수 있어요. 메뉴 이름이 다르면 비슷한 이름을 찾아보시고, 막히면 아래 "막히면" 방법으로 알려주세요.
2

1마침을 협업자로 초대하기 · 약 3분

아래 이메일 주소로 초대해주세요.

-

이렇게 해주세요
① Cloudflare에 로그인한 상태에서 계정 설정(Manage Account) 메뉴를 찾아요.
② 그 안의 멤버(Members) 항목에서 멤버 초대(Invite)를 눌러요.
③ 위 이메일을 입력하고, 권한(역할)은 사이트 배포와 도메인 연결이 가능한 관리자(Administrator)로 선택해 초대를 보내요.
④ 초대를 보내셨다면 마이페이지의 "배포 준비"에서 "초대를 보냈어요"에 체크해주세요.

초대만 해주시면 이후 코드 업로드, 도메인 연결, 테스트는 1마침이 모두 진행해요. 배포가 끝난 뒤에는 언제든 고객님이 멤버 목록에서 1마침을 직접 제거하실 수 있어요. 1마침은 계정 안에서 사이트 배포와 연결에 필요한 작업만 해요.

💡 초대 메일을 받는 쪽은 1마침이라 고객님이 따로 연락하실 필요는 없어요. 다만 이메일 주소를 한 글자라도 잘못 입력하면 초대가 안 가니 복사해서 붙여넣어주세요.
3

도메인(사이트 주소) 구매하기 · 약 10~15분

원하시는 주소(예: yourname.com)를 도메인 판매 업체(가비아, 후이즈 같은 국내 업체나 Namecheap 같은 해외 업체)에서 직접 구매하시면 됩니다. 보통 1년에 1만~2만원대이고, 주소 끝(.com, .kr 등)에 따라 가격이 달라요.

구매하실 때 확인해주세요
· 도메인은 고객님 명의로 구매하세요. 소유권도 갱신 비용도 고객님께 있어요.
· 첫해 가격과 갱신 가격이 다른 경우가 많아요. 결제 전에 갱신 가격을 꼭 확인해주세요.
· 자동 갱신 여부를 확인하세요. 갱신이 안 되면 사이트가 멈출 수 있어요.
· 구매 후 도메인 업체 계정에도 2단계 인증을 켜두시면 안전해요.
· 마음에 드는 주소가 이미 쓰이고 있으면 다른 끝(.kr, .net 등)이나 비슷한 이름으로 다시 검색해보세요.

💡 도메인 이름이 아직 정해지지 않았다면, 마이페이지 "배포 준비"에 희망하시는 이름 2~3개를 적어주세요. 사용 가능 여부를 같이 확인해드릴게요.
4

도메인 정보 알려주기

도메인을 구매하셨다면 마이페이지 "배포 준비"에 도메인 주소와 구매처 이름만 적어주세요. 호스팅과 도메인을 연결하는 작업(DNS 설정)은 1마침이 대신 진행해요.

도메인 업체에서 "네임서버"를 바꾸는 작업이 필요할 수 있어요. 그런 경우에는 바꿔야 할 값을 1마침이 마이페이지 문의 답변으로 알려드리고, 어디를 눌러야 하는지 글로 안내해드려요. 도메인 연결이 화면에 반영되기까지는 몇 분에서 최대 하루 정도 걸릴 수 있어요.

마이페이지에서 마지막으로 해주실 것
세 가지(계정 가입, 초대, 도메인)를 마치셨다면 마이페이지의 "배포 준비"에서 체크하고 도메인 주소를 적은 뒤 "배포 준비 정보 저장"을 눌러주세요. 모두 채워서 저장하시면 "준비 완료"로 접수되고, 그다음부터 마침이 배포를 진행해요.
막히면 바로 알려주세요. 마이페이지 "배포 준비" 칸의 "막혔어요, 문의하기" 버튼을 누르면 마이페이지 아래 "1:1 문의"창에 프로젝트 정보가 채워져요. 어느 단계에서 막혔는지, 화면에 보이는 내용을 글로 적어주세요. 답변은 같은 "1:1 문의"에 남겨드려요. 비밀번호와 인증번호는 절대 적지 마세요.
자주 막히는 부분
· 인증 메일이 안 와요 → 스팸함과 프로모션함을 확인하고, 5분 정도 기다린 뒤 다시 보내기를 눌러보세요.
· 초대 메뉴를 못 찾겠어요 → 로그인 후 왼쪽(또는 위쪽) 메뉴에서 "계정(Account)"을 먼저 눌러 보세요. 그래도 안 보이면 문의하기로 화면에 보이는 메뉴 이름을 적어 보내주세요.
· 도메인이 이미 있는 이름이래요 → 끝을 바꾸거나(.kr, .net) 이름을 조금 바꿔서 다시 검색해보세요.
· 결제수단 등록을 하래요 → 호스팅은 무료 요금제로 시작할 수 있어요. 결제 화면에서 막히면 멈추고 문의해주세요.
· 해외 업체 결제가 안 돼요 → 해외결제가 막힌 카드일 수 있어요. 국내 도메인 업체를 이용하시면 쉬워요.
요금제와 약관은 가입하는 회사의 기준이 적용돼요. 호스팅·도메인의 요금제, 사용량 한도, 갱신 비용은 고객님이 해당 회사와 직접 맺는 계약이라 제가 대신 정할 수 없어요. 가입할 때 요금제를 꼭 확인해주세요. 사이트를 영리 목적으로 운영하신다면 그 요금제가 영리 이용을 허용하는지도 함께 봐주세요. 서비스 회사의 정책이 바뀌어 다른 곳으로 옮겨야 할 때는 별도 유지보수(유료)로 도와드려요.
준비가 늦어지면 배포도 그만큼 뒤로 미뤄져요. 준비 요청일로부터 14일이 지나도 완료되지 않으면 다른 고객님 작업을 먼저 진행할 수 있고, 준비가 끝나면 가장 빠른 일정으로 이어서 배포해드려요. 자세한 내용은 이용약관 제4조 4-7에 있어요.
